# SimpleSender-Gemini GTK Companion

This folder contains an optional GTK CSS snippet for GTK-based file managers and dialogs.

Use it if you want the file/folder content area to better match the `SimpleSender-Gemini` Openbox theme.

Important:

- This is separate from the Openbox theme.
- Openbox controls window-manager chrome.
- GTK controls the interior content area of GTK file managers such as Thunar, PCManFM, and Nautilus.

Suggested install locations:

- GTK 3: `~/.config/gtk-3.0/gtk.css`
- GTK 4: `~/.config/gtk-4.0/gtk.css`

You can copy the contents of `gtk.css` into those files or adapt them into your existing GTK theme.
